# Published results only, no self-run evaluations

LLM Bench v1 aggregates scores published by providers, papers, and public leaderboards; it does not run its own evaluations or publish estimates, and it labels each score with its evaluation setting and source type. The alternative — a self-run pipeline — would require funded compute, reproducibility infrastructure, and continuous operation, which conflicts with a static, Git-backed site refreshed monthly. Self-runs are deferred until a dedicated owner and budget exist.
