# 12: CSV and JSON export

**What to build:** one-click export of both the current view and the whole dataset, so that analysts can take the numbers with their provenance intact.

**Blocked by:** 06 (weights and shareable URL state).

**Status:** ready-for-agent

- [ ] The default CSV and JSON exports contain the currently filtered and sorted rows, selected Benchmark columns, computed Average and Coverage, and provenance fields.
- [ ] A separate full-dataset export contains all raw Models, Benchmarks and Scores, including non-primary Evaluation settings.
- [ ] Exports reflect the active Benchmark selection and weights, and contain no hardcoded columns.
- [ ] Both export controls are keyboard-operable and labelled for assistive technology.
