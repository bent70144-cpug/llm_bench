# 08: Benchmark detail pages

**What to build:** a routed page for every Benchmark explaining what it measures and where it is weak, so that researchers can cite results responsibly.

**Blocked by:** 03 (benchmark catalogue and dynamic columns).

**Status:** ready-for-agent

- [ ] Each Benchmark has a directly addressable page reachable from the leaderboard.
- [ ] The page shows the description, metric, limitations, saturation and contamination notes, and evaluationSettingNotes taken from data.
- [ ] No Benchmark prose is hardcoded in the web app; adding a Benchmark creates its page automatically.
- [ ] Direct navigation and refresh work on Benchmark routes, and keyboard navigation reaches all content.
