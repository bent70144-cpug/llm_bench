# 13: Accessibility, responsiveness and performance

**What to build:** a site that works on a phone, with a keyboard, and at scale, so that every visitor can read the numbers quickly.

**Blocked by:** 05 (selection, Average, Coverage and ranking).

**Status:** ready-for-agent

- [ ] The wide table scrolls inside its own container on mobile without breaking the page layout.
- [ ] All controls are keyboard-operable with visible focus and sufficient contrast in both light and dark themes.
- [ ] The leaderboard stays responsive with 200+ Models loaded.
- [ ] A typical broadband page load completes in under two seconds.
- [ ] Browser-level checks cover mobile scroll, theme switching and keyboard operation against the built output.
