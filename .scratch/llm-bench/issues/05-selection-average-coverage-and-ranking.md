# 05: Selection, Average, Coverage and ranking

**What to build:** visitors can shape the leaderboard to their use case and read an honest ranking, so that sparse Models are not mistaken for fully measured leaders.

**Blocked by:** 04 (real Published Results for 20+ Models).

**Status:** ready-for-agent

- [ ] Toggling Benchmarks recalculates Average instantly in the browser and updates the footer with the number of Benchmarks used.
- [ ] Every Average is displayed with its Coverage count in the form (n/selected), and Models below 50% Coverage of the active selection carry a visible badge.
- [ ] Equal Averages break by higher Coverage and then alphabetical Model name; null-Average Models sort to the bottom.
- [ ] Sorting by any column, searching by Model or Provider, and filtering by License, Provider, price and Context window all work together.
- [ ] Only Primary scores feed Averages, highlighting and ranking.
