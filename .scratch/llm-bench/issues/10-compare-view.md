# 10: Compare view

**What to build:** a side-by-side comparison of 2 to 4 Models with complementary charts, so that a buyer can choose between finalists.

**Blocked by:** 06 (weights and shareable URL state), 09 (model detail pages).

**Status:** ready-for-agent

- [ ] A visitor can select 2 to 4 Models and see them side by side across all selected Benchmarks.
- [ ] A radar chart plots only the visitor's selected Benchmarks, capped at 8 axes with a clear note when more are chosen, prioritizing Benchmarks with Scores across the compared Models.
- [ ] A bar chart shows all selected Benchmarks, and missing values render as "n/a" instead of zero on both charts.
- [ ] The compared Models are encoded in the URL, so a comparison can be shared and survives refresh.
